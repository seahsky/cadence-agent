# cadence-agent

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues in `seahsky/cadence-agent`, managed through the `github` MCP server.
The `gh` CLI is banned in this repo — `.claude/settings.json` denies it.
See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role vocabulary, each label string equal to its role name.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root.
See `docs/agents/domain.md`.
